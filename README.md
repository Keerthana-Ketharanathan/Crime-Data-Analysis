# Crime Data Analysis – Power BI

## Project Overview

Crime Data Analysis is an interactive Power BI dashboard developed to analyze crime patterns, resolution status, geographical distribution, and trends over time. The project transforms raw crime data into meaningful visual insights using KPIs, charts, maps, and interactive filters.

## Dataset

The project uses a crime dataset containing information about crime types, countries, dates, resolution status, and people involved. The dataset was imported into Power BI and transformed for analysis and visualization.

## Analysis Performed

The dashboard analyzes:

- Total number of crimes
- Resolved vs. unresolved crimes
- Crime resolution percentage
- Crime trends over time
- Country-wise crime distribution
- Crime type analysis
- Geographical distribution of crimes
- Number of people involved
- Resolution status of crimes

## Dashboard Details

The dashboard includes KPI cards displaying Total Crimes, Resolved Crimes, Unresolved Crimes, Resolution Percentage, and Total People Involved.

It also includes visualizations for crime trends over time, country-wise crime analysis, resolution status, and geographical crime distribution.

Interactive slicers allow users to filter the dashboard based on crime type and country.
